# Public

Anyone at all. This repository is on GitHub under MIT/Apache-2.0, so a document
tagged `public` here is already world-readable before any site is built — the
tag says *this is meant to be read*, not *this is now visible*.

The site built for this audience is `exports.www`: the project's page on
[diaryx.org](https://diaryx.org), fronted by `www/index.md`. The org workspace
mounts it at `/fig/` when it builds the site; built here alone, it is the
same page at `/`.
